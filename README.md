# Iris Flower Classifier 🌸

A simple machine learning project that predicts the species of a flower based on its petal and sepal measurements.

## What does this project do?

Using the well-known Iris dataset, I trained a model that looks at a flower's sepal and petal measurements and predicts which of three species it belongs to (setosa, versicolor, or virginica).

## How it works

- Split the data into training and test sets
- Trained a Decision Tree classifier
- Tested the model on flowers it had never seen before

## Result

The model achieved about 96% accuracy on the test data.

## Tools used

- Python
- scikit-learn
